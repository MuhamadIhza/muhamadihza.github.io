Method

How a project moves through my hands

The same six stages every time, each with a deliverable the client can hold me to.

01 · Discovery

Ask before configuring

Workshops by function to separate real needs from old habits.

→ Kickoff questionnaire, as-is flowcharts
02 · Fit-gap

Standard first

Every requirement lands in one bucket: standard, Studio, automation rule, custom module, or process change.

→ Fit-gap matrix, solution comparison
03 · Configure

Upgrade-safe changes

Customizations through inherited views and rebuilt reports, never by editing what already works.

→ Configured database, customization log
04 · Migrate

Data people can trust

Cleansing with a change log so finance can audit every merge and rename.

→ Import-ready files, review flags
05 · UAT

Evidence over opinions

Scenario-based tests per process with expected results and screenshots.

→ UAT scenarios, sign-off sheet
06 · Go-live

Stay for the first month

Cutover checklist and hypercare until users stop needing me.

→ Cutover plan, SOPs, training
